# Keyboard shortcuts

The keys OLAD understands while you work on the map.

| Key                                                       | Effect                                                                                                                                                                                         |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Escape**                                                | Cancel the current step or tool. With no tool running: clear the selection.                                                                                                                    |
| **Enter**                                                 | Finish: close a line or polygon, insert a curve, continue after selecting objects, end a template insert. On the command line: send the typed text; on an empty command line: finish the tool. |
| **Backspace**                                             | While drawing: remove the last point. In step-by-step tools: go one step back. Otherwise: delete the selection.                                                                                |
| **Delete**                                                | Delete the selected objects. In the Vertices tool: remove the vertex under the pointer.                                                                                                        |
| **Ctrl+Z** / **Cmd+Z**                                    | Undo.                                                                                                                                                                                          |
| **Shift+Ctrl+Z**, **Ctrl+Y** / **Shift+Cmd+Z**, **Cmd+Y** | Redo.                                                                                                                                                                                          |

## With the mouse

| Action                                                                 | Effect                                                                     |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **Shift+click**                                                        | Add an object to the selection, or remove it.                              |
| **Ctrl+drag** / **Cmd+drag**                                           | Select with a box.                                                         |
| **Alt+click**                                                          | Vertices tool: remove a vertex. Measure tools: measure the clicked object. |
| **Double-click**                                                       | Finish a line or polygon.                                                  |
| **Right-click** or **press and hold** a toolbar button with a triangle | Choose a variant of the tool, for example how to draw a circle.            |
| Click a **grip** (⠿)                                                   | Open the menu to dock or float a toolbar or panel.                         |

The keys are ignored while you type in a field or while a dialog is open. Tools have no single-key shortcuts yet; start them from the toolbars.
