# API

All of this is importable from `ol-cad` (ESM) or available on the global `olcad` (UMD).

## `createEditor(config): Editor`

Validates the config (throws `ConfigError`, see [configuration.md](configuration.md)), registers proj4 projections, creates or attaches to the map, builds basemaps and layers and returns the editor. Layers load when the map first renders them.

**Ids of new objects.** Every inserted object gets a temporary id `tmp-<n>` (`feature.getId()`), counted per editor from 1. Undo and redo keep it. For a tracked layer it is the `tempId` of the `insert` entry in the change set. `changes.accept({ idMap })` replaces it with the id your backend returns, and a temporary id without an `idMap` entry stays. Do not store temporary ids: they are not unique across page loads. Objects in local layers and the draft layer never reach the change set and keep their `tmp-<n>` id; local layers restored by `localLayers.import` (and so by `persistLocalLayers`) get new ids `loc-<n>`.

### `editor.straightedge`

The parallel straightedge is the rotated crosshair shown in edit mode. Angles are in degrees, counter-clockwise from the screen x-axis (CAD convention), normalised to `[0, 360)`. The angle is screen-space: view rotation or a projection switch does not change it.

| Member          | Description                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getAngle()`    | Current x-axis angle. Initial value from `cursor.angle`.                                                                                                                                                                                                                                                                                                                                     |
| `setAngle(deg)` | Sets the angle (normalised). Updates the crosshair and emits `straightedgechange`.                                                                                                                                                                                                                                                                                                           |
| `getColor()`    | CSS colour of the crosshair lines and pick box. Initial value from `cursor.color`.                                                                                                                                                                                                                                                                                                           |
| `setColor(css)` | Changes the colour live (for example a light one over a dark basemap) and emits `straightedgechange`.                                                                                                                                                                                                                                                                                        |
| `pick()`        | Starts a reference pick: the pick box turns `cursor.pickColor`, the candidate segment under the pointer is highlighted in that colour, and the next click on a line or polygon of an editor layer (hit tolerance at least 8 px) sets the angle to that of the segment nearest to the click (`[0, 180)`). Clicks that hit nothing or a point keep the pick running. Throws outside edit mode. |
| `cancelPick()`  | Ends a running pick without changing the angle. Leaving edit mode and `destroy()` cancel too.                                                                                                                                                                                                                                                                                                |
| `isPicking()`   | Whether a reference pick is running.                                                                                                                                                                                                                                                                                                                                                         |

### `editor.measurements`

The measurements of the session (`MeasurementsApi`): distances, areas and angles, kept and drawn with labels on an overlay above the editor layers until removed. They are never part of a layer, the selection or the change set. The measure tools ([tools.md](tools.md#measurement)) and `<olcad-measure-results>` ([ui.md](ui.md#olcad-measure-results)) use this API.

| Member                            | Description                                                                                                                                                                                                                                                                                                                                                                         |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `list()`                          | `Measurement[]`: `{ id, kind: 'distance' \| 'area' \| 'angle', name, coordinates, holes?, values, label, source? }`; coordinates in the view projection (the points of a distance, the open outer ring of an area, first point, vertex and second point of an angle); `values` in metres, square metres and degrees (`length`, `segments`, `area`, `perimeter`, `angle`, `reflex`). |
| `get(id)`                         | One measurement, or `undefined`.                                                                                                                                                                                                                                                                                                                                                    |
| `add(kind, coordinates, extras?)` | Measures and keeps it (`extras`: `{ holes?, source?: { layer, featureId? } }`); names count per kind ("Distance 1"). Emits `measurechange`. Returns the measurement, or `null` with too few points (2 for a distance, 3 for an area or angle).                                                                                                                                      |
| `remove(id)`                      | Emits `measurechange`; `false` for an unknown id.                                                                                                                                                                                                                                                                                                                                   |
| `clear()`                         | Removes all; emits `measurechange` when there were any.                                                                                                                                                                                                                                                                                                                             |
| `getLive()`                       | The measurement in progress of a measure tool (`id: 'live'`), or `null`.                                                                                                                                                                                                                                                                                                            |

On `setProjection` the coordinates are transformed and the values kept. Helpers: `measureLength(projection, coords)`, `measureArea(projection, rings)`, `measureAngle(first, vertex, second)`, `formatLength`, `formatArea`, `formatAngle`, `computeMeasurement(projection, kind, coordinates, holes?)`, `MEASUREMENT_MIN_POINTS`.

### `editor.templates`

Templates are copies of objects (one or many, from any layers, read-only ones included) stored relative to a base point under a name, for the session. Tools `template-copy` and `template-insert` ([tools.md](tools.md#template-copy)) and `<olcad-template-list>` ([ui.md](ui.md#olcad-template-list)) use this API; the library never persists templates itself: `export` / `import` exchange plain JSON a host can save.

| `get(id)`                       | The `Template` `{ id, name, base, features: [{ layer, geometry, properties }] }`, geometries and base in the view projection, or `undefined`. Do not modify it.                                                                                                                                                                                                                                                                                                |
| `create(features, base, name?)` | Stores copies of the features (each must belong to a layer) relative to `base`; attributes are deep-copied without the layer's id property. ## Export

`editor.exportLayers(layerIds, { format, projection?, decimals? })` returns an `ExportResult` `{ content, mimeType, extension, filename, featureCount, skipped }`; nothing is downloaded or sent (the UI's [`<olcad-export-dialog>`](ui.md#olcad-export-dialog) downloads it). Any layer can be exported: configured, read-only, draft and local ones. The same writer is exported as `exportLayers(layers, options, viewProjection)` for features outside an editor; `EXPORT_FORMATS` lists the formats for a UI.

| `format`  | File                                                                                                                                                                                                                                                    |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `geojson` | One FeatureCollection; every feature gets the property `layer` (`_layer` when it already has a `layer` property). `projection` default `EPSG:4326`; another EPSG code adds a `crs` member (`urn:ogc:def:crs:EPSG::25832`).                              |
| `kml`     | Always EPSG:4326. One `<Folder>` per layer, named by its title; attributes as `ExtendedData`; no styles.                                                                                                                                                |
| `gml`     | GML 3.2: a `gml:FeatureCollection` with one feature type per layer (element named after the layer id, namespace `urn:ol-cad:export`), `gml:id` `{layer}.{id}`, `srsName` = `projection` (default EPSG:4326, written latitude first as the CRS defines). |
| `gpx`     | Always EPSG:4326. Points become waypoints, lines routes, multi-lines tracks (waypoints first); polygons and multi-points are skipped and counted in `skipped`. Objects without a `name` get `{layer title} {id}`.                                       |

`decimals` defaults to 7 for degrees and 3 for metric CRS. In XML formats, properties whose names are not valid element names are left out and object values are written as JSON text. The file name is the layer title for one layer, `export-YYYY-MM-DD` for several. Throws for no layers, an unknown layer or format, or an unregistered projection.

## Import

`editor.import` reads a file's text and inserts its objects; the UI's [`<olcad-import-dialog>`](ui.md#olcad-import-dialog) wraps it.

| Member                               | Description                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `read(text, { filename?, format? })` | `ImportPreview` `{ format, dataProjection, groups, skipped }`. The format comes from `format`, else the file extension (`.geojson`/`.json`, `.topojson`, `.kml`, `.gml`/`.xml`, `.gpx`), else the content; GML 2, 3 and 3.2 are told apart by namespace and coordinates. Throws `ImportError` with a readable message (invalid JSON or XML, a CRS that is not registered).                                                        |
| `targetsFor(group)`                  | Ids of the layers that can take every object of the group: insert allowed and the same geometry type, its multi-part form, or `Any`.                                                                                                                                                                                                                                                                                              |
| `apply(preview, targets?)`           | Inserts the groups as **one command** (one undo step). `targets[group.key]`: `{ type: 'new', title? }` (default: a new [local layer](#editorlocallayers) with the group's fields), `{ type: 'layer', id }` or `{ type: 'skip' }`. - **Groups** (`ImportGroup` `{ key, name, geometryType, features, fields, invalid }`): first by the file's own grouping — the `layer` property our GeoJSON export writes, TopoJSON objects, top-level KML folders (placemarks outside folders form one more group), GML feature types — then split into points, lines and polygons; a group with single and multi parts gets the multi type. - Also exported: `readImport(text, { filename?, format?, viewProjection })`, `applyImport`, `importTargets`, `IMPORT_FORMATS`, `ImportError` and the types `ImportApi`, `ImportFormat`, `ImportFormatInfo`, `ImportGroup`, `ImportPreview`, `ReadImportOptions`, `ImportTarget`, `ImportResult`, `ImportContext`.

## Custom tools

`BaseTool` and the `Tool` / `ToolContext` types are exported for hosts that want to add tools: implement `id`, `canActivate(ctx)`, `activate(ctx)` (set `this.interactions` before calling `super.activate`), and submit every change through `ctx.execute`. A multi-step tool implements `getPrompt()` and calls `ctx.promptChanged()` whenever the next step begins; a step that asks for a dimensionless number (a count, a factor) implements `handleValue(value)` and returns `true` to take a number typed without a unit; a step that asks for a length (a distance, a height) implements `handleLength(metres)`, which receives the typed length converted to metres; both are offered before a length is resolved as a distance; a step that asks for text (a name) implements `handleText(text)`, offered before any parsing; a step that expects the user to type (text or a value) returns `'text'` / `'value'` from `getInputRequest()`, so the input bar focuses and highlights itself; `ctx.done()` ends the tool itself (as `editor.tools.deactivate()`), `ctx.templates` reaches the template store, `ctx.measurements` the measurement store (`add`, `setLive`); a tool that changes no data sets `readOnly = true` and then runs with edit mode off too; `ctx.getStraightedgeAngle()` gives the straightedge angle for shapes aligned with it, `ctx.getProjection()` the view projection (for `unitsPerMetre` and `distanceMetres`) `ctx.getCurveTolerance()` the chord tolerance in metres for linearized curves, `ctx.getLengthUnit()` and `ctx.formatLength(metres)` the default unit for prompts (a prompt may also contain `{unit}`, which `editor.tools.getPrompt()` replaces with its symbol); `PointPickInteraction` (exported) hands a tool snapped clicks and moves plus the raw pointer position, and `pickTolerance(ctx)` is the grip pick radius in map units; the editor emits `toolprompt` and `<olcad-input-bar>` shows the text. Registration of host tools on the editor is planned for milestone 6.

## Edit mode

A single boolean on the editor, toggled by `setEditMode` and by the toggle in `<olcad-toolbar>`. It is the switch between viewing and editing; what it enables beyond the flag is defined with the tools in milestone 4 (tools only activate in edit mode, except read-only tools such as the measure tools, which also run while viewing).

While edit mode is on, the core draws a CAD-style crosshair in the map viewport: two one-pixel lines spanning the whole map on both axes that follow the pointer, with a small square (the pick box) at their crossing, and hides the native cursor over the map. The lines are rotated by the straightedge angle (see `editor.straightedge`). The overlay (`div.olcad-crosshair`, inline-styled, `pointer-events: none`) hides over OpenLayers controls and when the pointer leaves the map. Size and colour come from the `cursor` config (`pickBoxSize`, `color`); `cursor.crosshair: false` disables it. The map target element carries the class `olcad-edit-mode` (exported as `EDIT_MODE_CLASS`) meanwhile. Everything is restored by `setEditMode(false)` and by `destroy()`, so a host-owned map keeps its own cursor. Hosts can use `editmodechange` or the class to show or hide their own editing UI.

## Projections and measurement

Feature coordinates in memory are always in the view projection. The data projection of each loaded feature is kept alongside its original geometry (`getOriginalGeometry`) so the change set can be exported in the layer's data projection without round-trip loss. Measurement and numeric input (milestone 5) go through a projection-aware module; in `EPSG:3857` lengths are corrected for the scale at the working location.

## Script-tag build

`dist/ol-cad.umd.js` exposes everything above plus the UI exports on `window.olcad`. It expects the OpenLayers full build on `window.ol`, `window.proj4` when `projections` are configured, and `window.GeoTIFF` for `geotiff` basemaps.
